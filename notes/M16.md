# M16 · Templates: function/class templates, specialization, SFINAE basics

## Core ideas
```cpp
template <typename T>                       // function template: T deduced from arguments
T lerp(const T& a, const T& b, double t) { return a + (b - a) * t; }

template <typename T, std::size_t N>        // class template with a non-type parameter
class RingBuffer { std::array<T, N> buf_{}; std::size_t head_ = 0, size_ = 0; /*...*/ };

RingBuffer<ImuSample, 200> imu;             // N is a compile-time constant: no heap, size known
lerp(1.0, 3.0, 0.5);                        // T = double
lerp<double>(1, 3.0, 0.5);                  // explicit: needed because int vs double conflict
```

### Specialization
```cpp
template <> Angle lerp<Angle>(const Angle& a, const Angle& b, double t) { /* shortest arc */ }  // full spec. (functions)
template <typename T> struct IsAngle : std::false_type {};
template <> struct IsAngle<Angle> : std::true_type {};                // full spec. (class)
template <typename T> struct Traits<T*> { /* partial specialization: classes only */ };
```
Function templates can't be partially specialized → overload them, or dispatch to a class template.

### Constraining (SFINAE basics, C++17)
```cpp
template <typename T, typename = std::enable_if_t<std::is_floating_point_v<T>>>
T wrapAngle(T a);                                    // only participates for float/double
template <typename T> auto norm(const T& v) -> decltype(v.norm()) { return v.norm(); }  // expression SFINAE
static_assert(N > 0, "RingBuffer capacity must be positive");  // clear error instead of SFINAE
```

## What happens in memory / cost
| Thing | Cost |
|---|---|
| Template instantiation | Each distinct `<T, N>` generates its own code: zero runtime overhead, **code bloat** + compile time |
| `std::array<T,N>` member | Inline storage, `sizeof = N*sizeof(T)`; no allocation |
| Static dispatch | Fully inlinable, unlike virtual calls |
| Definition location | Must be visible at instantiation → templates live in **headers** (or explicit instantiation) |

## Template argument deduction rules
| Parameter | Argument `const int ci` | Deduced `T` |
|---|---|---|
| `T x` | `ci` | `int` (top-level const & refs dropped, arrays decay) |
| `const T& x` | `ci` | `int` |
| `T& x` | `ci` | `const int` |
| `T&& x` (forwarding) | lvalue `ci` | `const int&` |
| `T&& x` | rvalue `5` | `int` |
Conflicting deductions (`max(1, 2.0)`) are an error: no implicit conversions during deduction.

## Pitfalls interviewers ask
1. **Linker errors**: template defined in `.cpp` and used elsewhere → undefined reference.
2. **Dependent names**: `typename T::value_type x;` and `this->member` / `obj.template get<0>()`.
3. **`std::vector<bool>`** is a specialization (bit-packed proxy references); `auto& b = v[0]` fails.
4. **Specialization must be declared before first use** or you get the primary template silently (ODR issues).
5. **Function specialization vs overload**: overloads are chosen first; a full specialization is only picked if its primary wins.
6. **Eigen fixed-size members** in classes allocated with `new` (pre-C++17) needed `EIGEN_MAKE_ALIGNED_OPERATOR_NEW`.
7. `template <typename T> void f(std::vector<T>)` won't deduce from `{1,2,3}` (braced-init list isn't deduced).

## Robotics angle
- Eigen is the template showcase: `Matrix<double, 3, 1>` is `Vec<T,N>` done right; fixed sizes live on the stack.
- Ceres autodiff: cost functors are templates on `T` so the same code runs on `double` and `Jet`.
- Generic `RingBuffer<T, N>` for IMU/odometry history; `interpolate<T>` with a specialization for rotations
  (you cannot linearly interpolate angles/quaternions — use shortest-arc/slerp).
- Sensor traits (`SensorTraits<Lidar>::rate`) to pick behaviour at compile time.

## Rapid-fire questions
<details><summary>Show answers</summary>

- *Why are templates usually header-only?* The compiler needs the definition at each point of instantiation.
- *Template vs virtual?* Templates: compile-time, inlined, separate code per type. Virtual: one code path, runtime dispatch, heterogeneous containers.
- *What is SFINAE?* Substitution Failure Is Not An Error: an invalid substituted signature just removes that overload from the set.
- *Partial specialization of a function template?* Not allowed; overload or use a class template.
- *Non-type template parameter examples?* `std::size_t N`, `int`, enums, pointers; (C++20 adds floating point / class types).
- *What does `typename` before `T::iterator` do?* Tells the parser a dependent name is a type.
- *What does `static_assert` buy over SFINAE?* A readable error message at the point of misuse.
</details>

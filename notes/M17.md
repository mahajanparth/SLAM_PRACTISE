# M17 · Modern C++17: structured bindings, optional, variant, if constexpr, string_view

## Core ideas
```cpp
// Structured bindings: unpack pairs, tuples, structs, arrays
for (const auto& [name, rate] : rates) { ... }          // std::map<std::string,double>
auto [it, inserted] = map.try_emplace(key, value);
auto [x, y, z] = point;                                  // struct with public members

// std::optional<T>: "a T or nothing", stored inline (no heap)
std::optional<double> parseRate(std::string_view s);
if (auto r = parseRate(tok)) use(*r);                    // if-with-initializer + contextual bool
double hz = parseRate(tok).value_or(10.0);

// std::variant: type-safe union, holds exactly one alternative
using Msg = std::variant<LidarMsg, ImuMsg, OdomMsg>;
std::visit([](const auto& m) { return m.stamp; }, msg); // generic lambda handles every alternative
if (const auto* imu = std::get_if<ImuMsg>(&msg)) { ... }

// if constexpr: discard the untaken branch at compile time (inside templates)
template <class T> void handle(const T& m) {
  if constexpr (std::is_same_v<T, ImuMsg>) integrate(m.gyro);
  else log(m.stamp);
}

// std::string_view: non-owning (pointer, length) view of chars
std::string_view tok = line.substr(0, pos);   // NO allocation if `line` is a string_view
```

### Overloaded-lambdas idiom for `std::visit`
```cpp
template <class... Ts> struct overloaded : Ts... { using Ts::operator()...; };
template <class... Ts> overloaded(Ts...) -> overloaded<Ts...>;     // deduction guide (C++17)
std::visit(overloaded{ [](const LidarMsg& l) {...}, [](const ImuMsg& i) {...}, [](const OdomMsg& o) {...} }, msg);
```

### Other C++17 bits worth naming
`[[nodiscard]]`, `[[maybe_unused]]`, `inline` variables, fold expressions `(args + ...)`, CTAD
(`std::pair p{1, 2.0}`), `std::from_chars` (no locale, no exceptions), `std::clamp`, `try_emplace`/`insert_or_assign`.

## What happens in memory / cost
| Type | Layout | Cost |
|---|---|---|
| `std::optional<T>` | `T` + bool (padded) inline | No heap; `sizeof(optional<double>) == 16` |
| `std::variant<A,B,C>` | max(sizeof) + index | No heap; `visit` = jump table on the index |
| `std::string_view` | pointer + length (16 B) | Copy by value; `substr` is O(1) |
| `std::string::substr` | new string | Allocation (unless SSO ≤ 15 chars) |
| `std::any` | type-erased, may heap allocate | Avoid in hot paths |

## Pitfalls interviewers ask
1. **Dangling `string_view`**: `std::string_view sv = std::string("tmp");` or returning a view into a local string.
2. `string_view` is **not null-terminated**: don't pass `sv.data()` to `atof`/`strtod`/C APIs.
3. `*opt` on an empty optional is UB; `opt.value()` throws `bad_optional_access`.
4. `std::optional<T&>` doesn't exist; use `T*` or `std::reference_wrapper`.
5. `std::get<ImuMsg>(v)` throws `bad_variant_access` if wrong alternative; `get_if` returns nullptr.
6. `std::variant<std::string, bool> v = "lidar";` holds **bool** (pointer→bool conversion wins pre-C++20).
7. Structured bindings are names for members of a hidden copy unless you write `auto&`/`const auto&`.
8. Lambdas can't capture structured bindings in C++17 (`[x]` where `x` is a binding fails on GCC/Clang-strict).
9. `if constexpr` only discards branches that depend on a template parameter; outside templates both branches are checked.

## Robotics angle
- Config parsing / message decoding: `std::optional` for "malformed → nothing" without exceptions in a real-time thread.
- Sensor message buses: `std::variant<Lidar, Imu, Odom>` + `std::visit` instead of a polymorphic base: no heap, value semantics, the compiler checks that every message type is handled.
- `string_view` tokenizers for log/CSV/KITTI calibration files: zero allocations per token.
- Structured bindings over `std::map<std::string, SensorConfig>` and `auto [R, t] = decompose(T);`.

## Rapid-fire questions
<details><summary>Show answers</summary>

- *optional vs nullptr vs sentinel (-1)?* optional works for any value type, is explicit in the signature, and needs no magic value.
- *variant vs inheritance?* variant: closed set of types, value semantics, no heap, exhaustive visit. Inheritance: open set, needs pointers.
- *When is `string_view` dangerous?* When it outlives the buffer it points to (temporaries, reallocated strings).
- *What does `std::visit` cost?* An index-based jump table: about the cost of a virtual call, but no allocation.
- *What does `if constexpr` give over `if`?* The untaken branch is not instantiated, so it may contain code invalid for that `T`.
- *How do structured bindings work for a struct?* They bind names to the members of a (possibly reference-qualified) hidden object `e`.
- *`std::from_chars` advantages?* No allocation, no locale, no exceptions, reports error and end pointer.
</details>

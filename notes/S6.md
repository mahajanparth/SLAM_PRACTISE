# S6 · Registration

## Core ideas

### Kabsch / Umeyama (known correspondences, closed form)
$$\min_{R,t}\sum_i\lVert Rp_i+t-q_i\rVert^2:\quad \tilde p_i = p_i-\bar p,\ \tilde q_i=q_i-\bar q,\quad H=\sum_i\tilde p_i\tilde q_i^\top = U\Sigma V^\top$$
$$R = V\,\mathrm{diag}\big(1,1,\det(VU^\top)\big)\,U^\top,\qquad t=\bar q-R\bar p$$
Umeyama scale: $s = \mathrm{tr}(\Sigma D)/\sum_i\lVert\tilde p_i\rVert^2$ and $t=\bar q - sR\bar p$.
```cpp
const Eigen::Vector3d mp = P.rowwise().mean(), mq = Q.rowwise().mean();   // P,Q: Matrix3Xd
const Eigen::Matrix3d H = (P.colwise() - mp) * (Q.colwise() - mq).transpose();
Eigen::JacobiSVD<Eigen::Matrix3d> svd(H, Eigen::ComputeFullU | Eigen::ComputeFullV);
Eigen::Vector3d D(1, 1, (svd.matrixV() * svd.matrixU().transpose()).determinant() < 0 ? -1 : 1);
Eigen::Matrix3d R = svd.matrixV() * D.asDiagonal() * svd.matrixU().transpose();
Eigen::Vector3d t = mq - R * mp;
// Reference: Eigen::umeyama(P, Q, /*with_scaling=*/false) -> Matrix4d
```
*Why it works:* $\max_R \mathrm{tr}(RH)$ (orthogonal Procrustes). With the SVD it becomes $\mathrm{tr}(\Sigma\,V^\top R U)$, which is maximised by $V^\top RU=I$.

### Point-to-point ICP
```
T = init
repeat: P_i = T*s_i ; q_i = NN(tgt, P_i) ; drop |P_i-q_i| > gate ; dT = kabsch(P, Q) ; T = dT*T
until |dT| tiny or max_iters
```
- NN: KD-tree / voxel hash (brute force $O(NM)$ only for tiny clouds). Compare **squared** distances.
- Converges to a *local* minimum. The basin is roughly 20–30° and a fraction of the scene size.

### Point-to-plane (one Gauss-Newton step)
$$r_i(\delta) = n_i\cdot\big((I+[\omega]_\times)p_i + v - q_i\big) = \underbrace{n_i\cdot(p_i-q_i)}_{r_i} + \underbrace{\big[(p_i\times n_i)^\top\;\; n_i^\top\big]}_{J_i}\begin{bmatrix}\omega\\ v\end{bmatrix}$$
$$H=\sum J_i^\top J_i,\quad b=\sum J_i^\top r_i,\quad \delta=-H^{-1}b,\quad T\leftarrow \mathrm{Exp}(\delta)\,T$$
```cpp
Vector6d J; J << p.cross(n), n;   H.noalias() += J * J.transpose();  b += J * r;
Vector6d delta = H.ldlt().solve(-b);
dT.linear() = Eigen::AngleAxisd(w.norm(), w.normalized()).toRotationMatrix();  // guard w≈0
```
Pure translation is linear, so one step is exact. **Degeneracy:** $\lambda_{\min}(H)\ll\lambda_{\max}(H)$, and the eigenvector tells you which DOF is unconstrained.

### Scan-to-map odometry skeleton
```
scan → deskew → voxel downsample → register(local map, init = T_{k-1}(T_{k-2}^{-1}T_{k-1})) → keyframe? → map.add + removeFar
```
Local map = voxel hash (≤ N pts/voxel, `floor(p/v)` keys), keyframes by distance/angle, `std::function` registrator, producer/consumer thread for scans.

## What happens in memory / cost
| Step | Cost | Note |
|---|---|---|
| Kabsch | $O(N)$ + 3×3 SVD | SVD negligible; `JacobiSVD<Matrix3d>` is fixed-size and allocation-free |
| NN brute force | $O(NM)$ per iteration | fine for ~300 points only |
| NN KD-tree | $O(N\log M)$ | rebuild per map update; ikd-tree for incremental |
| NN voxel hash | $O(27Nk)$ | KISS-ICP; approximate but fast and dynamic |
| GN normal eqs | $O(N)$ accumulating a 6×6 | `H.noalias() +=` avoids temporaries |
| Isometry3d | 128 B (4×4 doubles) | `T.inverse()` uses the isometry structure (cheap) |

## Pitfalls interviewers ask
1. $t=\bar q-\bar p$ instead of $\bar q - R\bar p$.
2. No reflection guard. It *does* fire on planar scenes (rank-2 $H$, arbitrary sign of the third singular vector).
3. $UV^\top$ vs $VU^\top$: depends on whether $H=\sum \tilde p\tilde q^\top$ or $\sum\tilde q\tilde p^\top$.
4. Right- vs left-multiplying the increment: correspondences computed on $T\cdot s$ mean $T\leftarrow\Delta T\,T$.
5. Computing correspondences once and never updating them (that's just Kabsch, not ICP).
6. No distance gate, so dynamic objects and non-overlap pull the solution. Too tight a gate gives < 3 pairs; handle it.
7. Jacobian sign: $n\times p$ vs $p\times n$.
8. `CHECK(...)`/`const auto&` bound to `f().matrix()`: a reference into a destroyed temporary `Isometry3d`.
9. Drift of $R$ off SO(3) after many updates. Re-orthonormalise (quaternion normalise / SVD).

## Robotics angle
- **LOAM/LeGO-LOAM**: edge (point-to-line) + planar (point-to-plane) residuals, plus degeneracy remapping.
- **KISS-ICP**: constant-velocity prior, adaptive threshold, voxel-hash local map, point-to-point with a robust kernel.
- **FAST-LIO2**: IMU-propagated prior, point-to-plane inside an iterated EKF, ikd-tree map.
- **Loop closure**: global descriptor → coarse alignment (FPFH+RANSAC/TEASER++) → ICP refine → pose-graph edge.
- **Evaluation**: ATE needs Umeyama (Sim3 for monocular) to align the estimate to ground truth first.

## Rapid-fire questions
<details><summary>Show answers</summary>

- *Why does ICP need a good initial guess?* NN correspondences are only right near the solution; the cost is non-convex, so ICP finds a local minimum.
- *Point-to-point vs point-to-plane vs GICP/NDT?* P2P: simple, slow on planes. P2Pl: slides along surfaces, fast convergence, needs normals. GICP: plane-to-plane with covariances on both sides. NDT: per-voxel Gaussians, no explicit NN.
- *Detect degenerate registration?* Eigenvalues/condition number of $H=J^\top J$; small-eigenvalue eigenvectors are the unconstrained DOFs.
- *Convergence criteria?* $\lVert\Delta\text{pose}\rVert$ below threshold (rotation & translation), relative cost change, max iterations.
- *Outlier handling?* Distance gating, trimmed ICP (best x%), robust kernels (Huber/Cauchy via IRLS), normal-angle checks.
- *Minimum correspondences for Kabsch?* 3 non-collinear points.
- *Why Exp(ω) rather than I+[ω]× for the update?* It stays exactly on SO(3), and linearisation is used only for the step direction.
- *Real-time at 10 Hz?* Downsample, good prior, KD-tree/voxel hash, early stop, parallel NN.
</details>

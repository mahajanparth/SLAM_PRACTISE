# S7 · Nonlinear Least Squares: Gauss-Newton, LM, robust kernels, pose graphs

## Core ideas
Minimise $F(x) = \tfrac12 \sum_i \|r_i(x)\|^2_{\Omega_i}$. Linearise $r(x+\Delta) \approx r + J\Delta$:

$$H\Delta = -b,\qquad H = J^\top \Omega J,\quad b = J^\top \Omega r \qquad\text{(Gauss-Newton normal equations)}$$

```cpp
Eigen::MatrixXd H = Eigen::MatrixXd::Zero(n, n);
Eigen::VectorXd b = Eigen::VectorXd::Zero(n);
for (each residual i) {                 // accumulate, never build the full J for big problems
  H.noalias() += Ji.transpose() * Wi * Ji;
  b.noalias() += Ji.transpose() * Wi * ri;
}
Eigen::VectorXd dx = H.ldlt().solve(-b); // H is symmetric PSD -> LDLT / LLT
x += dx;                                 // on a manifold: x = x ⊞ dx  (e.g. R * Exp(dδ))
if (dx.norm() < 1e-10) break;
```

| Method | Step | When |
|---|---|---|
| Gradient descent | $\Delta = -\alpha\, b$ | robust but slow (linear convergence) |
| Gauss-Newton | $H\Delta = -b$ | fast near the minimum, small residuals; can diverge far away |
| Levenberg-Marquardt | $(H + \lambda I)\Delta = -b$ (or $\lambda\,\mathrm{diag}(H)$) | default choice; interpolates GD ↔ GN |

**LM rule:** compute step, evaluate new cost. Lower → accept, $\lambda \leftarrow \lambda/10$. Higher → reject (keep $x$), $\lambda \leftarrow 10\lambda$.

### Jacobians
- Central difference: $J_{:,k} \approx \dfrac{f(x+\epsilon e_k) - f(x-\epsilon e_k)}{2\epsilon}$, error $O(\epsilon^2)$; $\epsilon\approx10^{-6}$. Forward difference is $O(\epsilon)$.
- On SO(3), perturb through exp: $\dfrac{\partial\, R\,\mathrm{Exp}(\delta)\,p}{\partial \delta}\Big|_0 = -R\,[p]_\times$ ; left perturbation $\mathrm{Exp}(\delta)Rp$ gives $-[Rp]_\times$.

### Robust kernels (IRLS)
Huber with threshold $k$: $w(r) = 1$ if $|r|\le k$ else $k/|r|$. Cauchy: $w = 1/(1 + (r/c)^2)$.
Solve $J^\top W J\,\Delta = -J^\top W r$, recompute weights, repeat. Scale: $\sigma \approx 1.4826\cdot\mathrm{MAD}$, $k \approx 1.345\sigma$.

### SE(2) pose graph (Grisetti tutorial)
Pose $x_i = (t_i, \theta_i)$, edge $z_{ij} = (t_z, \theta_z)$:
$$e_{ij} = \begin{bmatrix} R_z^\top\big(R_i^\top (t_j - t_i) - t_z\big) \\ \mathrm{wrap}(\theta_j - \theta_i - \theta_z) \end{bmatrix}$$
$$A_{ij} = \frac{\partial e}{\partial x_i} = \begin{bmatrix} -R_z^\top R_i^\top & R_z^\top \frac{dR_i^\top}{d\theta_i}(t_j - t_i) \\ 0 & -1 \end{bmatrix},\qquad B_{ij} = \frac{\partial e}{\partial x_j} = \begin{bmatrix} R_z^\top R_i^\top & 0 \\ 0 & 1 \end{bmatrix}$$
Blocks: $H_{ii} \mathrel{+}= A^\top\Omega A$, $H_{ij} \mathrel{+}= A^\top\Omega B$, $H_{jj} \mathrel{+}= B^\top\Omega B$, $b_i \mathrel{+}= A^\top\Omega e$, $b_j \mathrel{+}= B^\top\Omega e$.
**Gauge:** fix $x_0$ by adding $10^{6}I$ to $H_{00}$ (or deleting its rows/cols).

### Schur complement / marginalisation
$$\begin{bmatrix}A & B\\ B^\top & C\end{bmatrix}\begin{bmatrix}\Delta_a\\ \Delta_c\end{bmatrix} = \begin{bmatrix}b_a\\ b_c\end{bmatrix} \;\Rightarrow\; (A - BC^{-1}B^\top)\Delta_a = b_a - BC^{-1}b_c,\quad \Delta_c = C^{-1}(b_c - B^\top\Delta_a)$$
BA: $C$ = landmarks (block-diagonal 3×3, cheap to invert) → reduced camera system. Sliding window: marginalising old states leaves a dense prior (fill-in).

## What happens in memory / cost table
| Operation | Cost |
|---|---|
| Dense $H$ for $n$ poses (3 dof) | $9n^2$ doubles; 50 poses → 22 500 doubles, fine |
| Dense Cholesky / LDLT | $O(m^3)$, $m$ = state dim |
| Sparse Cholesky (pose chain + few loops) | ≈ $O(m)$ – $O(m^{1.5})$ with good ordering (AMD/COLAMD) |
| BA Schur: invert $C$ (block-diag) | $O(\#\text{landmarks}\cdot 27)$, then dense solve on cameras only |
| Numerical Jacobian | $2n$ evaluations of $f$ |

## Pitfalls interviewers ask
1. **Sign of the step**: $H\Delta = -b$ with $b = J^\top r$. Mixing conventions moves you uphill.
2. **Angle residual not wrapped** → a ±2π jump wrecks the loop closure.
3. **Forgot the gauge** → $H$ is singular (rank deficient by 3 in SE2, 6 in SE3, 7 for monocular sim3).
4. **Perturbing rotation entries directly** in a numerical Jacobian leaves SO(3); perturb via $R\,\mathrm{Exp}(\delta)$.
5. `auto H = J.transpose()*J;` is an expression, re-evaluated each use. Assign to a `MatrixXd`.
6. Using `H.inverse()` instead of `ldlt().solve()`, which is slower and less stable.
7. Convergence check on cost *and* step norm; cap iterations; GN can oscillate or diverge from a poor init (use LM).
8. Huber threshold in the wrong units: it applies to the *whitened* residual.

## Robotics angle
- Every SLAM back-end (g2o, GTSAM, Ceres) is this loop: residuals → Jacobians → sparse $H$ → Cholesky → ⊞ update.
- Lidar odometry (ICP point-to-plane) is one GN step per iteration; loop closure adds an edge to the pose graph.
- Robust kernels / switchable constraints handle false loop closures.
- VIO sliding windows (OKVIS, VINS) marginalise via Schur; FEJ keeps the linearisation point fixed to avoid spurious information.

## Rapid-fire questions
<details><summary>Show answers</summary>

- *GN vs LM?* LM adds damping $\lambda I$: GN when it works, gradient descent when it doesn't; accepts or rejects steps.
- *What is the information matrix?* Inverse covariance, $\Omega = \Sigma^{-1}$; $H$ approximates the inverse covariance of the estimate.
- *Why is BA's H arrow-shaped?* Each observation couples one camera and one landmark only → block-diagonal camera and landmark blocks plus sparse coupling.
- *What is gauge freedom?* The cost is invariant to a global transform, so $H$ has a null space; fix one pose or add a prior.
- *Why central differences?* $O(\epsilon^2)$ truncation error vs $O(\epsilon)$ for forward.
- *Why Cholesky + reordering?* $H$ is SPD and sparse; good ordering (AMD) minimises fill-in.
- *What does marginalisation cost you?* Fill-in (dense prior) and a fixed linearisation point (hence FEJ).
- *iSAM2?* Incremental: Bayes tree, re-linearise and re-factor only the affected part.
</details>

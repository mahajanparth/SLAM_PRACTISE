# S8 · Estimation & Mapping: EKF, projection, triangulation, occupancy grids, A*, IMU

## Core ideas

### EKF (2D robot, known landmarks)
State $x=(x,y,\theta)$, covariance $P$ (3×3). Unicycle motion with $(v,\omega,\Delta t)$:
$$x' = x + v\Delta t\cos\theta,\quad y' = y + v\Delta t\sin\theta,\quad \theta' = \theta+\omega\Delta t$$
| Step | Equations |
|---|---|
| Predict | $\bar x = f(x,u)$, $\bar P = F P F^\top + Q$, $F=\partial f/\partial x$ |
| Innovation | $y = z - h(\bar x)$ (**wrap the bearing component!**) |
| Gain | $S = H\bar P H^\top + R$, $K = \bar P H^\top S^{-1}$ |
| Update | $x = \bar x + K y$, $P = (I-KH)\bar P(I-KH)^\top + KRK^\top$ (Joseph) |

$F=\begin{bmatrix}1&0&-v\Delta t\sin\theta\\0&1&v\Delta t\cos\theta\\0&0&1\end{bmatrix}$.
Range–bearing to landmark $m$: $d=m-p$, $q=d^\top d$, $r=\sqrt q$, $\phi=\operatorname{atan2}(d_y,d_x)-\theta$,
$$H=\begin{bmatrix}-d_x/r & -d_y/r & 0\\ d_y/q & -d_x/q & -1\end{bmatrix}$$
```cpp
double wrap(double a) { return std::atan2(std::sin(a), std::cos(a)); }
Eigen::Matrix<double,3,2> K = P * H.transpose() * S.inverse();   // S is 2x2: inverse() is fine
P = 0.5 * (P + P.transpose());                                    // keep it symmetric
```

### Pinhole + radial-tangential distortion
$x=X/Z,\ y=Y/Z,\ r^2=x^2+y^2$
$$x_d = x(1+k_1r^2+k_2r^4) + 2p_1xy + p_2(r^2+2x^2),\quad y_d = y(1+k_1r^2+k_2r^4) + p_1(r^2+2y^2) + 2p_2xy$$
$u = f_x x_d + c_x,\ v = f_y y_d + c_y$. If $Z\le 0$ (or tiny), the point is behind the camera, so flag it invalid.

### DLT triangulation
With normalized observation $(x,y)$ and $P=[R\,|\,t]$ (world→camera), each view gives two rows:
$x\,P_3 - P_1$ and $y\,P_3 - P_2$. Stack them into $A$ (4×4), take the right singular vector of the smallest singular value, then de-homogenize.
Cheirality: $(R X + t)_z > 0$ in both cameras.

### Occupancy grid (log-odds)
$\ell = \log\frac{p}{1-p}$, update $\ell \leftarrow \ell + \ell_{\text{meas}} - \ell_0$, clamp to $[\ell_{\min},\ell_{\max}]$, $p = 1 - \frac{1}{1+e^{\ell}}$.
Bresenham (all octants):
```cpp
int dx = std::abs(x1-x0), sx = x0<x1?1:-1, dy = -std::abs(y1-y0), sy = y0<y1?1:-1, err = dx+dy;
while (true) { visit(x0,y0); if (x0==x1 && y0==y1) break;
  int e2 = 2*err; if (e2 >= dy) { err += dy; x0 += sx; } if (e2 <= dx) { err += dx; y0 += sy; } }
```

### A* (8-connected)
`priority_queue<pair<double,int>, vector<...>, greater<>>` over $f=g+h$. Octile heuristic $h = (d_{\max}-d_{\min}) + \sqrt2\,d_{\min}$ is admissible and consistent. Skip stale heap entries (`if (f > g[idx]+h) continue`). No corner cutting: a diagonal move needs both orthogonal neighbours free.

### IMU integration (world frame, gravity $g=(0,0,-9.81)$)
$\hat\omega=\omega_m-b_g,\ \hat a = a_m-b_a$
$$p \leftarrow p + v\Delta t + \tfrac12(R\hat a+g)\Delta t^2,\quad v\leftarrow v+(R\hat a+g)\Delta t,\quad R\leftarrow R\,\operatorname{Exp}(\hat\omega\Delta t)$$
Update $p$ and $v$ with the *old* $R$ and $v$, then rotate.

## What happens in memory / cost
| Operation | Cost |
|---|---|
| EKF predict (fixed 3×3) | fixed-size Eigen, stack only, ~100 flops |
| EKF-SLAM update with n landmarks | $O(n^2)$ (dense $P$ is $(3+2n)^2$) |
| DLT: `JacobiSVD<Matrix4d>` | tiny and fixed-size; use `ComputeFullV` |
| Occupancy grid 2000×2000 `int8/float` | 4 M cells, 4–16 MB; tile/hash for big maps |
| A* | $O(E\log V)$ with a binary heap; Dijkstra = A* with $h=0$ |

## Pitfalls interviewers ask
1. **Unwrapped bearing innovation**: $z=\pi-0.01$, $h=-\pi+0.01$ gives an innovation of ~$2\pi$, and the filter explodes.
2. Covariance loses symmetry/PD from round-off, so use Joseph form or symmetrize.
3. `atan2(y, x)` argument order; the bearing is relative to $\theta$.
4. Projection of $Z\le0$ points gives mirrored pixels that look valid.
5. DLT with pixel coordinates without normalization is ill-conditioned (Hartley normalization); a small baseline means low parallax and huge depth uncertainty.
6. Bresenham written for one octant only (steep/negative slopes break); marking the endpoint free; no bounds check.
7. A*: marking nodes closed on push rather than on pop; an inadmissible heuristic (Euclidean × 1.5) loses optimality; diagonal cost 1.
8. IMU: forgetting gravity (or the sign), integrating $v$ before $p$, `R = R * exp` vs `exp * R` (body-frame gyro means right multiply).

## Robotics angle
- The EKF is the bread and butter of wheel+IMU+GPS fusion (robot_localization); error-state EKF for IMU (MSCKF, VINS).
- Projection + Jacobian ($2\times3$) is the core of bundle adjustment and of lidar→camera colorization.
- Triangulation initializes map points in visual SLAM (ORB-SLAM checks parallax + cheirality + reprojection).
- Occupancy grids drive 2D nav stacks (gmapping, cartographer submaps); A*/hybrid-A* plan on them.
- Preintegration (Forster) summarizes IMU between keyframes so the optimizer doesn't re-integrate when the linearization point changes.

## Rapid-fire questions
<details><summary>Show answers</summary>

- *KF vs EKF vs PF?* KF: linear Gaussian. EKF: mildly nonlinear and unimodal. PF: multimodal/non-Gaussian (global localization), cost grows with particles.
- *Why log-odds?* Bayesian updates become additions, there's no repeated multiplication of probabilities near 0/1, and clamping keeps the map adaptable.
- *Filtering vs smoothing?* Filtering estimates only the current state, so past linearizations are frozen. Smoothing re-optimizes the whole trajectory (or a window).
- *Why the Joseph form?* It stays symmetric PSD for any gain K, despite round-off.
- *Mahalanobis gating?* Accept an association if $y^\top S^{-1}y < \chi^2_{2,0.99}\approx 9.21$.
- *Why preintegration?* So you can relinearize without re-integrating raw IMU; bias changes are handled with first-order Jacobians.
- *Loop closure pipeline?* Place recognition (BoW/ScanContext) → geometric verification (RANSAC/ICP) → add edge → pose graph optimization.
- *Is the octile heuristic admissible on an 8-grid with costs 1/√2?* Yes, it's the exact cost on an empty grid.
